# Contribuição

Crie uma branch curta, mantenha commits focados e abra pull request. Antes do envio execute `npm ci`, `npm audit --audit-level=high` e `npm run build`. Não inclua `.env`, dados reais, segredos, `dist/` ou `node_modules/`. Mudanças de contrato devem atualizar README e `swagger.json`. Contribuições externas exigem revisão; não há push direto na branch principal.
