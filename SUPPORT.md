# Suporte e versões

Este projeto é uma referência personalizável. A hospedagem, o código alterado e a política de segurança da cópia são responsabilidade de quem a publica. O RecoPay mantém o contrato da API documentado e não recebe segredos no frontend. Use versionamento semântico; atualizações incompatíveis serão registradas no `CHANGELOG.md`.
